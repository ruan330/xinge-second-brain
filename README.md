# 鐘興鵝的第二大腦

這是一個用 Obsidian 維護的個人知識庫（Second Brain）。

> ⚠️ 本 vault 中的人物、學校、公司、事件全部為虛構，僅供教學示範使用。

## 資料夾結構

| 資料夾 | 內容 |
|---|---|
| `00-Home.md` | 入口頁（MOC），所有主題從這裡連出去 |
| `01-課程/` | 這學期的課程筆記、課表、作業 deadline |
| `02-專題/` | 畢業專題「校園公車到站提醒 LINE Bot」的紀錄與會議記錄 |
| `03-讀書筆記/` | 書籍、線上課程、技術文件的筆記 |
| `04-日記/` | 每日紀錄，檔名為 `YYYY-MM-DD.md` |
| `05-人脈/` | 教授、同學、實習同事的資料 |
| `06-待辦/` | 本週待辦與長期目標 |
| `07-實習/` | 雲杉科技實習的週報 |
| `08-報告/` | AI 或自己整理出來的報告都放這裡 |
| `templates/` | Obsidian 範本 |

## 使用方式

- 用 Obsidian 開啟這個資料夾即可。
- 筆記之間用 `[[wiki link]]` 互相連結。
- 每篇筆記開頭有 YAML frontmatter，至少包含 `tags` 與 `created`。
