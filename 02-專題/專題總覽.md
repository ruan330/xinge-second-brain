# 畢業專題：校園公車到站提醒 LINE Bot

## 一句話

學生在 LINE 上訂閱某個站牌，公車快到的前 5 分鐘收到推播，不用再站在站牌前面等。

## 目前狀態（09/08）

- ✅ 校園 3 號線可以訂閱與推播
- ✅ 後端跑在 Lambda + DynamoDB
- ⚠️ 推播有時候晚 2-3 分鐘，懷疑是 EventBridge 排程一分鐘一次不夠細
- ❌ 後台管理頁還沒接 API
- ❌ 沒有做多路線
