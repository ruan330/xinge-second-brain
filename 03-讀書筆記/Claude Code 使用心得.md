# Claude Code 使用心得

實習的時候 [[黃珮瑜]] 叫我用 Claude Code 寫測試，用了三週的心得。

## 跟網頁版 ChatGPT / Claude 的差別

| | 網頁聊天 | Claude Code |
|---|---|---|
| 看得到我的程式碼嗎 | 要自己貼 | 直接讀整個 repo |
| 能跑指令嗎 | 不能 | 能跑 test、git、npm |
| 能改檔案嗎 | 只能給我貼 | 直接改，還會問我要不要 |
| 記得專案脈絡嗎 | 每次重來 | 有 CLAUDE.md 就記得 |

一句話：網頁版是「問問題」，Claude Code 是「請人做事」。

## 好用的地方

- 叫它「幫這個函式寫測試」，它會先讀函式、讀既有測試的風格、再寫，風格跟專案一致。
- 叫它「找出為什麼 CI 掛了」，它會自己跑 test 看錯誤。
- CLAUDE.md 寫專案規則，它就會遵守（例如 commit 訊息格式）。

## 踩過的坑

- 一次叫它改太多東西，改到我看不完。要拆小。
- 它有時候會很有自信地說「修好了」但沒跑測試，要叫它跑。
- 權限模式要搞清楚，不然它每個指令都問。

## 想法

- 專題的 [[專題技術架構]] 那些 Lambda 可以叫它幫忙寫測試。
- 這個 vault 如果給它讀，它應該可以幫我整理 deadline。
- 珮瑜說公司在評估 Kiro（AWS 出的類似工具），下週會給我試。
