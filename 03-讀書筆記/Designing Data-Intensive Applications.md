# Designing Data-Intensive Applications（DDIA）

[[許承翰]] 學長推薦的，說「大三看不懂沒關係，大四再看一次就懂了」。

## 第 1 章：可靠、可擴展、可維護

- **可靠性**：硬體會壞、軟體有 bug、人會犯錯，系統要能容錯。
- **可擴展性**：描述負載的參數（QPS、讀寫比、活躍使用者），描述效能（percentile 比平均值有用）。
- **可維護性**：可操作、簡單、可演化。

跟 [[雲端運算導論]] 講的高可用是同一件事：假設東西會壞，設計成壞了也能跑。

## 第 2 章：資料模型

- 關聯式 vs 文件式 vs 圖。
- 文件式適合一對多、資料自包含。專題的訂閱資料用 DynamoDB 就是文件式的思維。
- 關聯式適合多對多。

## 第 3 章：儲存與檢索

- LSM tree vs B-tree。
- 讀到一半，OLTP 跟 OLAP 的差別看懂了，column store 還沒看懂。
